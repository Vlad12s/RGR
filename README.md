# Розрахунково-графічна робота (РГР)
## Інформаційна система управління замовленнями

Автори: Єрмак В.М та Гришкевич С.О 
Група: КІ-242  
Дисципліна: Організація баз даних  

---

## 📌 Опис проєкту

Даний проєкт є веб-інформаційною системою управління замовленнями, розробленою в межах розрахунково-графічної роботи.  
Система реалізує повний цикл роботи з базою даних через графічний інтерфейс та підтримує CRUD-операції.

Проєкт наближений до реальної прикладної системи та демонструє практичні навички роботи з БД, серверною логікою та користувацьким інтерфейсом.

---

## 🎯 Мета роботи

- Реалізувати інформаційну систему з графічним інтерфейсом
- Забезпечити повноцінну взаємодію з базою даних
- Реалізувати CRUD-функціонал
- Реалізувати валідацію та обробку помилок
- Навчитись працювати з Git та GitHub

---

## 🧩 Функціонал системи

- 📦 Управління товарами (Products)
- 📋 Управління замовленнями (Orders)
- ➕ Додавання записів
- ✏️ Редагування записів
- ❌ Видалення записів
- 👁️ Перегляд даних
- ✅ Валідація введених даних
- ⚠️ Обробка помилок користувача

---

## 🖥️ Інтерфейс користувача

Система має простий та інтуїтивний веб-інтерфейс, який дозволяє:
- працювати з базою даних без знання SQL;
- виконувати CRUD-операції;
- отримувати повідомлення про помилки;
- переглядати дані у табличному вигляді.

---

## 🗄️ База даних

База даних спроєктована з урахуванням нормалізації.  
Використовуються пов’язані таблиці для зберігання даних про:
- товари;
- замовлення;
- додаткові сутності системи.

ER-діаграма наведена у презентації до роботи.

---

## 🛠️ Використані технології

- PHP — серверна логіка
- MySQL — система керування базами даних
- PDO — безпечна робота з БД
- HTML / CSS — інтерфейс користувача
- Docker — розгортання проєкту
- Git / GitHub — контроль версій
